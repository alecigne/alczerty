#+title: alczerty

alczerty is my personal AZERTY-based keyboard layout. The only change
incompatible with standard AZERTY is the =ù= key, which becomes a dead
key. This single modification opens a world of possibilities for French
typography and additional symbols.

* Layout

The source of truth is [[file:layout/alczerty.toml][layout/alczerty.toml]], built with
[[https://github.com/OneDeadKey/kalamine][Kalamine]]. Its installation identifier is =alczerty=.

Press and release =ù=, then press the second key shown below. For the
Shift column, hold Shift while pressing the second key. For example,
=ù= then =e= produces =é=; =ù= then Shift + =e= produces =É=.

| Second key | After ù                    | After ù, with Shift               |
|------------+----------------------------+-----------------------------------|
| a          | à                          | À                                 |
| e          | é                          | É                                 |
| r          | è                          | È                                 |
| u          | ù                          | Ù                                 |
| c          | ç                          | Ç                                 |
| o          | œ                          | Œ                                 |
| q          | æ                          | Æ                                 |
| w          | «                          | unassigned                        |
| x          | »                          | unassigned                        |
| t          | –                          | —                                 |
| <          | ≤                          | ≥                                 |
| =          | ≈                          | ≠                                 |
| ù          | ù                          | Ù                                 |
| space      | U+00A0 (nonbreaking space) | U+202F (narrow nonbreaking space) |

Try the sequences with =just preview= before activating the layout.

* Preview and build

Install [[https://github.com/casey/just][just]], Python 3.11 or newer, and Kalamine. The initial build is
validated with Kalamine 0.40:

#+begin_src sh
  uv tool install kalamine==0.40
  just preview
#+end_src

=just preview= starts Kalamine's browser preview with live reload.
To build distributable files:

#+begin_src sh
  just build
#+end_src

Output is written to =dist/=, which is excluded from Git. These commands
can also be run directly:

#+begin_src sh
  kalamine watch layout/alczerty.toml
  kalamine build layout/alczerty.toml
#+end_src

* Use on Linux

On X.Org, run this from the project directory to build and activate the
layout:

#+begin_src sh
  just use
#+end_src

This requires =xkbcomp=. It loads the standalone
=dist/alczerty.xkb_keymap= into the current X session. No system
installation or =sudo= is required.

=just install= optionally installs the generated XKB symbols system-wide
and requires =sudo=.

For automatic activation at login, add the following command to your
desktop's X11 session startup, replacing the path with this project's
absolute path:

#+begin_src sh
  just --justfile /absolute/path/to/azerty-alc/Justfile use
#+end_src

To return to standard French AZERTY:

#+begin_src sh
  setxkbmap fr
#+end_src

=just clean= removes generated files from =dist/=. Run =just= to list
all commands. For Wayland and other platforms, consult Kalamine's
[[https://github.com/OneDeadKey/kalamine#using-distributable-layouts][distributable layout instructions]]; platform installation has not been
validated.

* Development

Build and use the layout directly from source. See [[file:CHANGELOG.org][CHANGELOG.org]]
for changes.

When changing mappings, preserve familiar base and Shift behavior and
existing AltGr symbols. Document any intentional exceptions and rebuild
the layout before activating it.
