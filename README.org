#+title: alczerty

alczerty is an AZERTY-based keyboard layout.

The only change incompatible with standard AZERTY is the =ù= key,
which becomes a dead key. This single modification opens many
possibilities for French typography and additional symbols.

The idea of a dead key comes from [[https://qwerty-lafayette.org/][QWERTY-Lafayette]].

* Why use alczerty?

alczerty builds on existing AZERTY habits. Letters, numbers,
punctuation, and AltGr symbols stay in their familiar places, so
there is little to relearn when adopting it or switching back to a
standard French keyboard.

The single compromise is =ù=: typing it now takes two presses.
In return, that key gives access to accented capitals, ligatures,
French quotation marks, nonbreaking spaces, and extra symbols.
The usual lowercase accents remain available directly on AZERTY;
the dead-key sequences provide another way to type them, with
Shift giving their uppercase forms.

This keeps the learning effort focused on the characters you need.
You can keep typing as usual and learn the extra sequences gradually.
The aim is better access to French typography with a small change
to everyday typing habits.

* Layout

Press and release =ù=, then press the second key shown below. For the
Shift column, hold Shift while pressing the second key. For example,
=ù= then =e= produces =é=; =ù= then Shift + =e= produces =É=.

|------------+----------------------------+-----------------------------------|
| Second key | After ù                    | After ù, with Shift               |
|------------+----------------------------+-----------------------------------|
| a          | à                          | À                                 |
| e          | é                          | É                                 |
| r          | è                          | È                                 |
| u          | ù                          | Ù                                 |
| c          | ç                          | Ç                                 |
| o          | œ                          | Œ                                 |
| q          | æ                          | Æ                                 |
| w          | «                          | unassigned                        |
| x          | »                          | unassigned                        |
| t          | –                          | —                                 |
| <          | ≤                          | ≥                                 |
| =          | ≈                          | ≠                                 |
| ù          | ù                          | Ù                                 |
| space      | U+00A0 (nonbreaking space) | U+202F (narrow nonbreaking space) |
|------------+----------------------------+-----------------------------------|

** Linux (X.Org)

There are two ways to activate alczerty:

|-------------+------------------------+-------------------------------------------------------------------------|
| Tool        | File                   | How it activates the layout                                             |
|-------------+------------------------+-------------------------------------------------------------------------|
| =setxkbmap= | =alczerty.xkb_symbols= | Selects installed symbols by name, using the system's XKB configuration |
| =xkbcomp=   | =alczerty.xkb_keymap=  | Loads the standalone keymap directly from its file path                 |
|-------------+------------------------+-------------------------------------------------------------------------|

*** xkbcomp: load the standalone keymap

The standalone keymap can be kept anywhere. Load it by its path to
activate the layout in the current X session. From the directory
containing the extracted files, run:

#+begin_src sh
  xkbcomp alczerty.xkb_keymap "$DISPLAY"
#+end_src

This requires =xkbcomp= and no =sudo=. For a permanent copy in your
home directory, run:

#+begin_src sh
  install -Dm 0644 alczerty.xkb_keymap "$HOME/.local/share/alczerty/alczerty.xkb_keymap"
#+end_src

You can then activate that copy with the command below. For automatic
activation at login, add it to your desktop's X11 session startup:

#+begin_src sh
  xkbcomp "$HOME/.local/share/alczerty/alczerty.xkb_keymap" "$DISPLAY"
#+end_src

The standalone keymap implements the dead key differently from the
symbols file, so modifier customizations can affect the two methods
differently.

*** setxkbmap: install and select by name

Install the symbols file in the system's XKB directory, then select
=alczerty= by name to activate it in the current X session. From the
directory containing the extracted files, run:

#+begin_src sh
  sudo install -m 0644 alczerty.xkb_symbols "${XKB_CONFIG_ROOT:-/usr/share/X11/xkb}/symbols/alczerty"
  setxkbmap alczerty
#+end_src

Installation requires =sudo=; selecting the installed layout does not.
For automatic activation at login, add =setxkbmap alczerty= to your
desktop's X11 session startup.

The symbols file uses =Mod3= for the dead key. Custom modifier
mappings, including those applied with =xmodmap=, must preserve that
assignment.

*** Return to standard AZERTY

With either method, return to standard French AZERTY with:

#+begin_src sh
  setxkbmap fr
#+end_src

For Wayland, follow Kalamine's [[https://github.com/OneDeadKey/kalamine#using-distributable-layouts][distributable layout instructions]].

** macOS

Copy =alczerty.keylayout= to =~/Library/Keyboard Layouts/=, creating
the directory if needed. Log out and back in, then add the layout in
your keyboard input source settings.

** Windows

Run =alczerty.ahk= with [[https://www.autohotkey.com/download/1.1/][AutoHotkey 1.1]]. Press both Alt keys together
to enable or disable it.

The =alczerty.klc= file can be opened in MSKLC or KbdEdit to build a
native installer. See Kalamine's [[https://github.com/OneDeadKey/kalamine#using-distributable-layouts][installation instructions]] for the
steps and limitations of custom dead keys with MSKLC.

macOS, Windows, and Wayland usage have not been validated for this
layout.

* Working from source

The source of truth is [[file:layout/alczerty.toml][layout/alczerty.toml]], Its installation
identifier is =alczerty=.

You will need Python 3.11 or newer and [[https://github.com/OneDeadKey/kalamine][Kalamine]].

#+begin_src sh
  uv tool install kalamine==0.40
#+end_src

All commands below can be simplified by using [[https://github.com/casey/just][just]]; check the
[[file:Justfile][Justfile]].

** Activate from source on Linux (X.Org)

Run these commands from the project directory. Choose either of the
two activation methods described in the installation section.

To build and activate the standalone keymap with =xkbcomp=:

#+begin_src sh
  just use
#+end_src

This loads =dist/alczerty.xkb_keymap= into the current X session. It
requires no =sudo= or system installation.

To build and install the symbols file, then activate it with
=setxkbmap=:

#+begin_src sh
  just install
  setxkbmap alczerty
#+end_src

=just install= requires =sudo= and copies the symbols file into the
system's XKB directory. It does not activate the layout; the
=setxkbmap= command does that. Re-run =just install= after changing
the source to update the installed file.

Both =just use= and =just install= build automatically. With either
method, =setxkbmap fr= returns to standard French AZERTY.

To uninstall the symbols file, run =just remove=; this requires =sudo=
and does not change the active layout.
