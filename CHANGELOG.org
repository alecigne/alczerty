#+title: Changelog

* X.Org activation

- Make =just use= build and load the standalone XKB keymap.
- Avoid the Mod3 collision between the symbols-file dead-key latch and
  Hyper mappings, which prevented dead-key input in Firefox.
- Document activation at login.

* Dead key on ù

- Add dead-key sequences for ≤, ≥ and ≈ on <, > and = respectively.
- Add ≠ on the dead key followed by Shift + =.
- Turn the base =ù= key into a dedicated dead key; keep Shift + ù as =%=.
- Add sequences for accented letters, ligatures, guillemets, en/em
  dashes, and nonbreaking spaces. Type =ù= twice for a literal =ù=.
- Remove the added AltGr typography shortcuts; use dead-key sequences
  for accented capitals, ligatures and guillemets.
- Restore ordinary spaces on AltGr + Space and Shift + AltGr + Space.
- Keep standard AZERTY AltGr symbols and other base and Shift mappings.

* Development

- Start alczerty as a single layout extending classic French AZERTY.
- Preserve familiar base and Shift mappings and existing AltGr symbols.
- Add direct accented capitals, ae/oe ligatures, guillemets, and
  nonbreaking spaces through AltGr combinations.
- Provide preview, build, and Linux XKB installation commands.
